# fire random shadow jagen - a chaos-like ROM hack for fire emblem shadow dragon (FE11)


A random event can happen every turn - ranging from simple stat modifications to major effects that change units, people, and weapons at the same time.

Some events include:
- Simple stat buffs/nerfs
- Tactical nuke
- Jegenify
- Dumbass Lena
- Crapshoot
- JAGEN19
- Canto is surprisingly hard to program so I took a shortcut
- John Shadow Dragon
- About 15 more


Some things it does not include:
- Custom assets
- A bug-free experience


I may do bug and balance fixes in the future but this was an inside joke turned into a weekend project that I eventually decided I would share, so after I drop the gambling patch do not expect any more updates (note: after the gambling patch this ROM hack will be appropriately called "gamble random shadow jagen").


# Important notes
- Only works on the US version
- I have not thoroughly tested this mod
- I recommend playing on any of the hard difficulties, balancing is most likely incomplete (see point above)
- Cheats might not work
- WiFi/networking capabilities are not possible (that would be crazy)


# How to play it
- Download the xdelta patch
- Apply it to a US ROM dump of FE11 with [delta patcher](https://github.com/marco-calautti/DeltaPatcher) or an [online tool](https://www.marcrobledo.com/RomPatcher.js/). The sha1/md5 hashes for the supported ROM are:
    - sha1: 7b7b307ef819ac31a7b71aed2e8e47ff23c1765e
    - md5: 3f2a22a9949df0f65e4b886089c2395b
- Emulators: I do most of my debugging and development with melonDS, but it has booted in desmume (I only tested booting in desmume, if it doesn't work go to melonds)
- Hardware: I have an r4i flash cart and a modded DSi. The flash cart works, but running it off the SD card via [nds-bootstrap](https://github.com/DS-Homebrew/nds-bootstrap) did not work for me (I am using an old version though)
- You can see the current effect(s) in the "Suspend" menu (suspending/in-map save points are not tested and I assume will break something)
